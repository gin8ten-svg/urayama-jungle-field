# サイト監査（site-audit）

画像の「監査・チェック」列にあたるスキル。**作ったら必ず監査してから出す**。

## 手順

1. 監査スクリプトを実行する（出力はスクラッチパッドなど、リポジトリの外に置く）。
   ```bash
   node .claude/skills/site-audit/scripts/audit.mjs index.html <scratchpad>/audit
   ```
   - NG が1つでもあると exit code 1 になる。
2. `<出力先>/report.md` を読む。
3. **スクリーンショットを必ず目で見る**（Read で png を開く）。
   - `desktop-top.png` / `mobile-top.png`：最初に見える画面。見出しが読めるか、装飾が文字に重なっていないか。
   - `desktop-full.png` / `mobile-full.png`：ページ全体。カードが崩れていないか、余白が不自然でないか。
   - 自動チェックで拾えない「見た目の違和感」はここで判断する。
4. 結果を次の形でまとめてユーザーに報告する。
   - **直すべき（NG）**：表示や検索に実害があるもの
   - **直したほうがよい（注意）**：品質を上げるもの
   - **見た目の所見**：スクリーンショットから気づいたこと
5. ユーザーが直すように言ったものだけ直す。直したらもう一度このスキルを実行して、NG が消えたことを確かめる。

## 注意
- 監査のために `index.html` を書き換えない。
- `audit-output/` をリポジトリ内に作った場合は commit しない（`.gitignore` 済み）。
